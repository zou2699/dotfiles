# Yazi 文件管理器配置指南

Yazi 是一个用 Rust 编写的现代终端文件管理器，具有强大的定制能力和高性能。本指南将帮助您配置 Yazi 以获得最佳使用体验。

## 目录结构

```
~/.config/yazi/
├── yazi.toml          # 主配置文件
├── keymap.toml        # 键位映射配置
├── theme.toml         # 主题配置
└── plugins/           # 插件目录（可选）
```

## 配置文件说明

### 1. yazi.toml - 主配置文件

主配置文件包含 Yazi 的核心设置：

#### [manager] 部分
- `ratio = [1, 4, 3]` - 左中右三栏的宽度比例
- `sort_by = "alphabetical"` - 默认排序方式
- `sort_dir_first = true` - 目录优先显示
- `show_hidden = false` - 默认不显示隐藏文件
- `scrolloff = 5` - 滚动时的边距

#### [preview] 部分
- `max_width = 600` - 预览窗口最大宽度
- `max_height = 900` - 预览窗口最大高度
- `image_quality = 75` - 图片预览质量

#### [opener] 部分
定义不同类型文件的打开方式：
- `edit` - 文本编辑器（使用 $EDITOR 环境变量）
- `open` - 系统默认打开方式
- `reveal` - 在文件管理器中显示
- `extract` - 解压缩文件
- `play` - 媒体播放器

### 2. keymap.toml - 键位映射

键位映射分为不同的模式：

#### 管理器模式 [manager]
基本导航：
- `hjkl` - Vim 风格的方向键
- `g+g` / `G` - 跳转到顶部/底部
- `Ctrl+u` / `Ctrl+d` - 半页滚动

文件操作：
- `Space` - 选择/取消选择文件
- `v` - 进入可视模式
- `y` - 复制文件
- `x` - 剪切文件
- `p` - 粘贴文件
- `d` - 删除到回收站
- `D` - 永久删除

高级功能：
- `s` - 使用 fd 搜索文件名
- `S` - 使用 ripgrep 搜索文件内容
- `z` - 使用 zoxide 跳转目录
- `Z` - 使用 fzf 跳转目录

排序快捷键（`,` 前缀）：
- `,m` - 按修改时间排序
- `,s` - 按大小排序
- `,a` - 按字母顺序排序
- `,e` - 按扩展名排序

#### 输入模式 [input]
- Vim 风格的编辑功能
- `i` / `a` - 插入/追加模式
- `hjkl` - 光标移动
- `w` / `b` - 单词级移动

### 3. theme.toml - 主题配置

主题配置采用 Gruvbox 配色方案：

#### 颜色定义
- `#1d2021` - 深色背景
- `#ebdbb2` - 浅色前景
- `#83a598` - 蓝色（目录、边框）
- `#b8bb26` - 绿色（执行文件、选择标记）
- `#fabd2f` - 黄色（媒体文件、搜索关键词）
- `#fb4934` - 红色（删除标记、PDF）
- `#fe8019` - 橙色（压缩文件、激活项）

#### 文件类型颜色
- 图片文件 - 蓝色
- 视频/音频 - 黄色
- 压缩文件 - 橙色
- PDF 文档 - 红色
- 可执行文件 - 绿色
- 目录 - 蓝色

## 高级功能

### 搜索功能
1. **文件名搜索** (`s`)：使用 fd 工具快速搜索文件名
2. **内容搜索** (`S`)：使用 ripgrep 搜索文件内容
3. **交互式跳转** (`z`)：集成 zoxide 进行智能目录跳转

### 预览功能
- 支持图片预览（需要 ueberzug 或类似工具）
- 文本文件语法高亮
- 压缩文件内容预览
- 媒体文件信息显示

### 选择和批量操作
- 使用 `Space` 选择单个文件
- 使用 `v` 进入可视模式批量选择
- 支持正则表达式选择
- 批量复制、移动、删除操作

## 依赖工具

为了获得最佳体验，建议安装以下工具：

```bash
# 文件搜索
brew install fd ripgrep

# 目录跳转
brew install zoxide fzf

# 图片预览
brew install ueberzug

# 解压缩
brew install unar

# 媒体播放
brew install mpv
```

## 使用技巧

1. **快速导航**：使用 `g+字母` 快速跳转到常用目录
2. **批量重命名**：选择多个文件后使用 `r` 进行批量重命名
3. **文件过滤**：使用 `f` 快速过滤当前目录的文件
4. **标签页管理**：使用 `t` 创建新标签页，数字键切换标签页
5. **任务管理**：使用 `w` 查看后台任务进度

## 自定义配置

您可以根据需要修改配置：

1. **修改键位映射**：编辑 `keymap.toml` 添加自定义快捷键
2. **调整主题颜色**：编辑 `theme.toml` 使用您喜欢的配色方案
3. **添加文件类型规则**：在 `yazi.toml` 中定义新的文件打开方式
4. **安装插件**：在 `plugins/` 目录下添加 Lua 插件扩展功能

## 故障排除

如果遇到问题：

1. **配置不生效**：检查配置文件语法是否正确
2. **预览功能异常**：确认相关预览工具已安装
3. **键位冲突**：检查终端模拟器的键位设置
4. **性能问题**：调整预览设置或增加缓存大小

这套配置提供了一个功能丰富且高效的文件管理体验，您可以根据个人喜好进一步调整。
